# 游戏专用检测器研究工具

这些脚本保留此前 Apex / Delta 专用模型实验的方法，供离线复查和复用。
它们不接入默认启动入口，也不会自动替换生产模型或配置。

2026-09-26：用户暂停三角洲方向；光斑生成 GUI、光斑专项训练和索敌实验
工具已移除。这里保留的 Delta 分支仅用于历史实验复查，不代表继续推进该方向。

| 脚本 | 用途 |
| --- | --- |
| `game_specialists.py` | 数据准备、固定种子训练、检测框评估及共用辅助函数 |
| `evaluate_game_specialists.py` | 根据验证集锁定候选，再评估保留测试集 |
| `export_game_specialists.py` | 将锁定候选导出为原生推理使用的 TensorRT 格式 |
| `check_game_specialists_native.py` | 使用原生预处理核对导出模型及历史实录样本 |

## 使用边界

- 这是历史实验脚本，不是通用训练入口。数据和输出路径主要固定在
  `artifacts/game-specialists-20260914/`，部分检查还依赖此前录像审计产物。
  数据、权重及这些产物不随源码提交；新机器需先准备相应输入。
- 评估及原生核对脚本会同时读取 Apex / Delta 两组历史产物，不能在只有
  Apex 数据时直接运行整套流程。单游戏准备、训练和导出入口见对应源码。
- Python 依赖包括 NumPy、OpenCV、Pillow、PyTorch 和 Ultralytics；模型导出
  还依赖 TensorRT / ONNX 工具链，原生验证需要编译好的 Vision 模块。
- 两种原始人体标签在这里都映射到 `person`，检测结果不能作为敌我判定。
- PyTorch 检测框指标和批量推理耗时不等于原生运行效果或实战验收。
- 本次整理仅检查语法和模块导入，没有重新训练、导出或部署模型。
