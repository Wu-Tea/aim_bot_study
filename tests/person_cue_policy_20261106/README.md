# 人物优先与 cue 遮挡续接

用户于 2026-11-06 确认：可信人物是主要目标证据，敌军标识不额外加人物权重；cue 主要负责机瞄遮挡等场景的接续。首次只有 cue 时允许用可调下移量临时定位。旧基线为当前 dev 提交 `64d930bd8d23fe6c74896f19c9b3b707f368a9dc`，没有切换工作区版本。

## 规则与职责

| 当前证据 | 行为 |
| --- | --- |
| 人物 + 友军标识 | 拒绝目标 |
| 人物，无标识 | 正常人物准入和完整 observed 权限 |
| 人物 + 敌军标识 | 与无标识人物相同权重；配对记录用于遮挡续接 |
| 人物消失，原 cue 仍可见 | 沿用已配对的身体偏移，保留现有 cue-only 权限 |
| 首次只有敌军 cue | 唯一候选通过原有两帧确认后，用 cue 下方可调位置辅助索敌；不伪造人物框、不授予开火权限 |
| 人物和 cue 均消失 | 当前帧不授予瞄准权限，身份保留仍由原有状态机管理 |

“完整人物权重”不意味着忽略模型置信度或几何有效性。人物统一使用初次准入 0.42、跟踪 0.40；唯一且置信度至少 0.50 的人物可单帧准入。0.20–0.40 的模型弱证据仍只允许关联原目标，不因标识而升权。

模块边界：

- `native/pipeline_contract/person_target_policy.h`：人物置信度准入规则，选择器与适配层共用。
- `native/vision_native/include/vision_native/person_cue_association.h`：人物与 cue 的空间关联几何。
- `native/vision_native/src/cue_acquisition_policy.cpp`：首次 cue 的搜索区域、歧义排除、下移定位；无历史状态。
- 原有选择器状态机：确认、身份、切换、丢失，以及配对几何的归属。
- 控制链：显式接收首次 cue 定位许可，继续使用现有 ADS 生命周期、手动权限和 cue-only 输出规则。

人物附近的标识检查和已配对 cue 跟踪每帧保留。更大范围的首次 cue 搜索只在没有人物候选且没有待续接身份时执行，同帧完成；不增加等待帧、不降频。删除了按“没有敌军标识”降权的规则，以及新统一阈值下已无效的意图准入例外。

回放还复现了一个相邻缺陷：新准入的无关人物候选会掩盖原目标当前有效的弱检测。修复位于选择器的候选/身份交接处：把原目标弱证据纳入同一次身份选择，不靠额外等待或历史坐标填补。

控制链专项也复现了 cue → 人物时把几何校正当作运动速度的问题。现在线路在采用真实人物坐标的同一帧重建人物运动测量起点，保留目标身份；不会拿临时偏移点与真实 box 点的差值训练速度。

## 配置

桌面“目标与识别”中增加“仅标识时向下偏移”：

```toml
[runtime.vision]
cue_pickup_offset_y_px = 40
```

范围为 0–512，单位是采集图像像素，修改后重启助手。40 只是可调的初始值，不代表已测得的人物高度。出现真实人框后立即改用既有 box 瞄点（包括用户的 25% 设置），并更新实际配对偏移。重置清除学习到的几何，但保留配置。

## 已知边界

- 冷启动的固定下移量缺少人物尺度信息，远近距离下可能存在偏差；真实人框出现后才有实际几何校准。
- BO7 长血条仍走原有形状过滤；短小血条碎片可能满足 cue 形状条件的旧限制没有在这次修改中消除，不能宣称不会误识别。
- 视频回放和确定性仿真不能替代实战验收；此次没有改模型、控制器输出算法、Profile 力度或检测频率。
