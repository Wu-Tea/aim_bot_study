# 产品定义问卷

这是一个完全本地运行的产品决策表单，用来在重构前确定：产品边界、目标身份、人体落点、人工意图、cue、开火／压枪、安全退路、游戏适配，以及 benchmark 的仿真与验收标准。

它不会修改 C++ 配置或业务代码，也不会把答案上传到任何服务。

## 使用方法

最简单的方法是直接双击 `index.html`。如果浏览器限制本地文件下载或剪贴板，也可以在项目根目录运行：

```powershell
python -m http.server 8765 --directory tools/product_questionnaire
```

然后打开 <http://127.0.0.1:8765>。

## 填写规则

- “核心决策”必须选择答案，或标记为“需要讨论”，才能通过当前章节。
- “深入细节”默认折叠，不阻塞进度，可以暂时跳过。
- 每道题都能补充说明，也能在已有暂定答案的同时标记“需要讨论”。
- 答案会自动保存在当前浏览器的 `localStorage` 中；关闭页面后可以继续。
- 条件不适用的问题会自动隐藏，不进入完成度统计。

## 填完以后

进入“最终复核”，导出：

1. `JSON`：交给 Codex 做结构化 review；
2. `Markdown`：给人阅读和留档的备份。

JSON 中包含答案、选项原文、补充说明、待讨论标记、适用性和完成度。把导出的 JSON 文件发回当前 Codex 任务即可。review 的目标是先找出产品定义里的冲突、遗漏和风险，确认以后才进入 benchmark 方案和 C++ refactor。

## 数据恢复

“答案工具”支持导入之前导出的 JSON。清空答案需要二次确认；清空后如果没有导出文件，浏览器内的内容无法恢复。
