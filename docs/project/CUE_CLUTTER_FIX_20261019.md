## 根因与修改

视觉已选择同代际cue_hold，但普通detections列表仍有未选中残框。adapter保留这些框用于候选/诊断；controller以前只在候选数为0时构造cue观测。这样，新鲜cue被残框挤掉，coordinator又正确拒绝残框的普通id，结果进入缺帧并在原期限停止输出。

修改仅在`native/controller_native/native_gamepad_controller.cpp`观测转换：有已授权的selector_cue_continuation时，不把未选中的人体框送入控制候选列表；用现有构造规则生成唯一cue观测。原始snapshot、detections和选择诊断保留。普通人体路径不变，cue的generation/已有身份/几何/距离/时效检查仍由coordinator负责。

没有增权、修改cue力系数、手动意图/仲裁、胸部比例、最低追赶、求解器、噪声参数或32/40ms；没有添加丢目标后的输出压制或延迟。这是在正式观测与诊断候选的责任边界消除根因，不是遮盖最终输出。

最明显的变差：独立104395489、case1、20秒、固定手动X=-.30与静止目标对抗。

- 3%：旧残框版本后段189.924px，新261.218px；修复前无残框参考原本就是261.218px，修复后完全不变。
