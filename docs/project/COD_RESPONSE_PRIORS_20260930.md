## 配置和行为

在 `config.toml` 的 `[gamepad.ai_aim]` 中使用 `body_free_initial_scale`、`body_slow_initial_scale`、`ads_free_initial_scale`、`ads_slow_initial_scale`。每项允许 0 或 80～4000；0 保留旧的继承规则。普通区未配置时使用既有 `aim_response_initial_scale` / 适配器校准；减速区未配置时继承对应普通区的生效值。

明确配置减速区初值后，它独立于普通区的新学习。两个区域分别按本区新置信度混合本区初值和学习值，再按目标空间位置连续混合。

明确配置 ADS 初值时，ADS 控制从启动起使用 ADS 估计器。原来“至少 8 个样本、置信度至少 0.35 才切换到 ADS 估计”的保护继续适用于未配置 ADS 专属初值的旧配置。配置初值本身不提供学习置信度。

Apex 和 BO3 分块显式设四项为 0，保留原来的共用 650 初值。鼠标适配器继续使用自己的校准。既有力度、响应曲线、压枪、目标选择和手动意图规则不变。

GUI 的游戏参数页可修改四项初值。支持热重载：重建响应估计器并清理学习证据/命令采样历史，保留当前目标身份和 ADS 生命周期。升级前已经运行的旧进程必须先重启，以加载新增配置支持。
