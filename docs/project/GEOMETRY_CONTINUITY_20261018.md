# 0.65 边界的胸部参考连续性修复

本次修复在源几何估计层去掉瞄点与区域高度的硬切换。普通和宽扁两端的配置比例保持原值，手动权、源瞄点所有权、ADS/BodyLock 状态机和 32/40 ms 限制均不修改。没有新增时间延迟、历史状态或用户开关。

## 原因与实现

`body_aim_geometry` 原来用高宽比是否低于 0.65，同步切换两种瞄点比例与区域高度。宽 100 px、顶部 Y=220、普通/宽扁比例 0.20/0.65 时，框高 64.8→65.2 px 使瞄点从 262.12 跳至 233.04。真实 selector/controller 探针保持同一 target_id，但 Y 输出反向；区域边界也随之跳动。

现在以高宽比 0.30 和 1.00 为宽扁/普通参考锚点，中间使用 `t²(3−2t)` 空间权重。瞄点比例与区域半高共用该权重；结果只依赖当前输入。区间外分别完全保留原宽扁和普通参考，过渡点的斜率连续。0.30 对应当前最扁有效身体框，1.00 是宽高相等的形状；它们是当前几何估计的设计锚点，不是经人体姿态标注验证的解剖事实。

0.65 分类仍用于既有证据与开火策略，不再控制瞄点/区域公式。框形状不证明头部可见性，不引入胸到头切换。GUI 原生预览协议升级 v4，导出相同锚点并在 Python 绘图侧复现 float32 算术；旧协议被明确拒绝，避免新旧公式混用。

同一探针中，修复后源 Y 从约 247.665 到 247.584，变化约 **0.081 px**，输出 Y 保持同向。这只证明所测边界的几何连续性，不代表实机抖动幅度。

## 必须保留的比较差异

| 场景，每组 128 例 | 原版平均误差 px | 修复后 px | 改善 / 变差案例 |
| --- | ---: | ---: | ---: |
| 明确敌方证据，无手动输入 | 8.524 | 1.772 | 128 / 0 |
| 明确敌方证据，含手动输入 | 112.009 | 112.957 | 106 / 22 |
| 无敌方证据，无手动输入 | 17.021 | 20.425 | 48 / 80 |
| 无敌方证据，含手动输入 | 123.971 | 129.835 | 72 / 56 |

这些是固定 tracking 窗口内按 tick 加权的误差，包含丢目标和人为反向输入；不能用一个总体均值充当验收分数。变差案例没有删去。

轨迹说明了差异来源：旧几何跳变使不少案例不能正常完成 ADS，继续保持 ADS 权限；修复后稳定到点，正常进入 BodyLock。无敌方证据时应用原有弱证据降权；强制手动把目标带出 BodyLock 跟随范围时，按原规则不再辅助。例如短案例 2 第 500 ms，旧版仍是 ADS、权限 1；新版已是 BodyLock、权限 0.2208；第 650 ms 手动带出范围后权限为 0。状态与输出见 `before-boundary/traces/`、`after-boundary/traces/`。

这不是要求把 BodyLock 调强的依据。本次保留这些规则，不让几何噪声通过延长 ADS 绕过它们。明确敌方证据且无手动输入时，四个种子全部案例改善；其他条件下不承诺误差全面下降。实机是否仍有弱证据跟随不足，需要新日志确认后单独研究，不能从模拟结果推断已验收。
