## 修复与原反例

| 问题 | 根因与改动 | 对照结果 |
| --- | --- | --- |
| person→cue 后 BodyLock 范围收缩 | Coordinator 只在 Observed 状态使用身体尺寸，cue 的同身份有效身体参考被当成零尺寸。现继续使用已验证尺寸；原时效和输出门槛保留。 | 固定几何 12 案例的来源切换断控由 6 个降为 0。220 px 身体、145 px 偏移不再因进入 cue 状态超出 120 px 基础范围。 |
| 命中提示误当 cue、旧身体参考错续 | 独立 detector 将四个黄色尖角分别当作紧凑标记。现识别准星周围同色对称四角组合；同时，当前强 person 与 cue 平移身体不兼容时作废旧配对。 | 原始 BGRA 帧的四个假 cue 变为 0；dev 帧 22810→22811 的约 279 px 错跳消失，22811 不再输出假目标。 |
| 不均匀采样产生定向速度偏置 | 逐样本截断速度破坏正负位移抵消。现保存原始增量，在 25 ms 窗口内按每轴峰值使用统一限幅比例，再积分与使用原有 slew。上限仍为 1.25，没有新增 Profile 参数。 | 256 个 2/20 秒探针中，绝对偏置超过 50 px/s 的案例由 180 个降为 0；±20 px、8/17 ms 的约 ±240 px/s 偏置变为约 0。 |
| cue 已到达仍不能完成 ADS | 到达计数和过中心只接受 person。现允许同身份连续新 cue 提供到达证据，并计算 cue→cue 的采集间位移；来源切换不算到达、不跨来源判过中心。 | 原探针 cue 200 ms 到中心后，交接由等待 person 返回的 1616 ms 提前到 224 ms；person 对照仍为 216 ms。 |
| 两个人交叉时 generation 不变但换了人 | 多个匹配框按距上一帧胸部最近决定归属，交叉时偏向迎面人物。现用 selector 自己的强人体中心运动预测做关联距离；40 ms 内有效，不用 cue/弱框训练人体运动，等价歧义停止当帧 person 输出。 | 原 32 场景串换由 10 个降为 0；另 128 个独立种子/帧率/间距/检测顺序组合通过。反向、短缺帧、明确手动换目标等回归通过。 |

强 person 的胸部算法没有被 cue 的颜色位置替代。圆点/死敌骷髅仍走原紧凑标记提议；本次不是按骷髅细节分类，也没有屏蔽整个准星中心区域。组合过滤仍是几何判别，不能保证识别所有部分遮挡或不同外观的 HUD。

速度估计的统一限幅会保守缩小含超限抖动窗口的净速度。实际 dev 三帧的屏幕净位移参考为 −80 px/s，在假设响应 1400 下，估计由错误方向的 +296.667 变成 −48.611 px/s；这是方向错误修复，不是精确恢复世界速度。直接取消单帧限幅的中间方案曾使旧阶跃回归退步，未保留；最终方案通过原回归，未放宽阈值。

最差残留反例仍存在于 `71020543 / case96`：dev 半径切换窗口、无手动、2 秒、响应 1899、执行延迟 27 ms、观测延迟 19 ms，平均误差 93.532→138.030 px；20 秒 case102 为 94.227→137.254 px。新 Vision 后仍存在，不能归咎于已消除的命中提示。当前只能确认扩大有效 cue 范围与速度估计修改后的完整链在此压力条件下有退步，尚未通过独立因果实验定位到新的单一根因；本轮没有修改力上限、手动权重、延迟或 Profile 来掩盖它。

录像残差包含原玩家相机运动。拟真把这些屏幕几何作为外部扰动，再叠加模拟相机，未重渲染图像，也未让 selector 接收模拟 Controller 的 intent/reset 回流，因此不是实战命中率或真实目标世界轨迹。完全不可区分的人物交叉也没有外观真值保证。实机重点观察 ADS 收尾、长 cue 跟随、交叉保持及高延迟下的过冲。
