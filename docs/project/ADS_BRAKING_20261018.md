# 保留最低追赶速度，让刹车不再被重新放大

用户明确要求：人物框内不能因游戏减速而拖慢拉枪，最低位置输出要保留；但拉枪、跟随和保持的共同目的，是稳定停在胸部目标点上。本次修复只调整 ADS 追赶参考与刹车的组合，不通过延迟、开关、取消最低参考或降低用户配置隐藏问题。

## 根因和改动

clean `866bd9c` 的新日志显示，两次慢开镜都在开火前发生左右越过中心和纵向输出突增。源点/期望点一致，首段框高宽比约 2.1–2.4，没有触发先前 0.65 几何边界。当前 Profile 的最低参考为 0.5；文件在会话后保存过，未将其当作完整历史配置快照。

生产求解器反例证明，原算法在位置需求与速度刹车抵消后，再把剩余向量抬回最低输出。接近取消时，几乎为零的需求仍得到约 0.344 杆量；完全抵消才突然归零。二维归一化还会把 X 刹掉的预算转移到未变化的 Y。缺陷属于 `response_model_aim_solver.cpp` 的需求组合，不属于手动仲裁或胸部参考。

修复先从未刹车的位置需求建立最低追赶增益，再将同一个增益用于位置与已受限的速度项。刹车之后只执行原有上界，不能补回最低值。位置力限不提前削弱远距离的饱和请求；追远目标仍服从原有范围与二维物理力限。原有响应曲线、25 ms 近点预算和 12 ms ADS lookahead 未改值，未添加历史状态、时间等待或用户选项。

这保留了静止目标尚未到点时的最低追赶参考，又允许足以到点的接近速度消减需求。参考不是无条件维持的最低速度：若已有运动会把准心送过目标，就必须能刹到零。BodyLock、胸部几何、逐轴手动权、Profile、开火和 32/40 ms 策略均未修改。

## 验证与行为比较

原版两个新增核心回归失败、修复后通过；最低参考与远距离饱和追赶回归通过。日志中 50 对几何观测进入 92 个曲线/响应组合反例，原版失败、修复版通过。源日志与重建限制见 [夹具说明](../../tests/ads_braking_20261018/README.md)。DEV 完整 51 组 CTest 通过，GUI 81 项及真实 WebView2 交互通过。

最终开发种子 2026101819/32452867；独立验证 104395303/67867979。每分支新场景 256 例、2,816,000 tick；旧日志混合场景另 128 例、1,408,000 tick。表中是逐案例均值，每组各 64 例，短长场景等权；不是按 tick 加权或游戏分数。

| 场景 | 原版平均误差 px | 修复后 px | 平均误差改善案例 |
| --- | ---: | ---: | ---: |
| 静止目标、慢开镜、明确敌方证据 | 10.711 | 8.217 | 55/64 |
| 移动目标，含弱证据 | 12.913 | 13.596 | 29/64 |
| 遮挡、开火与框形变 | 27.352 | 23.776 | 44/64 |

静止组后段位于真实目标点 4 px 内的时间比例从 54.1% 提升到 70.1%；平均中心穿越数 73.66→54.67。首次进入 20 px 邻域 102.97→105.23 ms，首次进入 2 px 125.03→143.36 ms，两者均无缺失。首次穿过点比旧版稍晚，后段保持更好；这与用户优先稳定到点的目标一致，不能说所有速度指标同时改善。

移动组平均误差和后段误差变差，不能删去。更早/不同的 ADS 完成会改变进入原有 BodyLock 的时机，弱证据仍按旧规则降权；真实移动目标的持续跟随仍需实机评估。遮挡后的源框变形也不是本次求解器修复消除的问题。高响应、长延迟等个别静止案例仍不稳定，完整 CSV 保留这些失败表现。

首次实现曾提前削弱远距离饱和请求，已在最终实现中去除，并新增独立回归；最终独立验证采用未用于该修改的两枚新种子。日志反例只对最低参考拥有的未饱和需求检查正交相机需求，二维力限的合法重分配由相邻随机测试覆盖。

## 产品同步和实机边界

clean 从 `866bd9c` 新建 `codex/ads-braking-20261018` 临时分支，仅同步求解器和当前架构说明；测试与实验留 DEV。clean 候选四份新场景 CSV 与 DEV 完全相同，实际 GUI 初始化、模型加载、Applied 热更、IPC 与正常停止通过，检查使用独立配置且关闭输出/震动。完整原生外置检查与合并后构建的最终结果记录在 `runs/ads-braking-20261018/results.json` 和 `.agent-context/handoff.md`。

32 ms 仍限制缺帧预测，超过 32 ms、未到 40 ms 只保留身份/未完成 ADS，辅助瞄准和开火权为零；达到 40 ms 释放。没有实机游戏验收结论，下一轮重点检查慢开镜到点后的停稳、人物框内追赶、移动目标跟随与人工反向/释放。
