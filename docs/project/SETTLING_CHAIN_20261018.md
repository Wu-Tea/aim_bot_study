# 用同一套位置与运动预算完成追赶、停稳和跟进

用户要求优先整体停稳，保留最低追赶速度、胸部参考、手动权和原 capture 的 32/40 ms 边界，不提高权限、不增加控制等待或用户开关。这次处理的是观测、相机运动、位置求解和阶段交接的职责冲突。

## 根因与责任层

20:31 录像最后三秒对应 clean `e08cb92` 会话 `20261018T123137Z_25292_1`。最后 ADS 在 20:32:12.822 开始，13.730 判定完成、13.739 进入 BodyLock；之前已经出现横向往返。源胸部点与期望点一致、目标 ID 未变，不能归因于胸部参考被手动移动；此前开火脉冲也已存在，稀疏记录的单个 `final_fire=false` 不能证明未开火。

生产反例将误差 -30/-30/-22/-14/-6 px 按 10 ms 输入：真实接近速度为 800 px/s，但旧开火扰动逻辑将其压到约 60，ADS 因而继续追赶。另一个反例中 solver 已归零，0.5 杆量的整形余量仍需约 11 ms 才消失；6 ms 时仍约 0.212。只修 solver 的最低值重放大，无法处理这些已经存在的相机工作。

阶段交接还把物理相机响应先验从 ADS 模型切到 BodyLock 模型；已存的归一化目标运动没有携带其响应单位，模型改变就会改变解释出的物理速度。真实命令生效时差与配置不符时，相机位移又被误算为目标移动，形成持续跟进和刹车互相影响的闭环。

修复分别落在信息的拥有者：

1. **TargetCoordinator 保留真实 capture 接近速度。** 开火扰动抑制仍服务于运动分类；它不能同时替代刹车/到达证明需要的源误差变化率。没有改变胸部位置。
2. **生产 controller 根据实际交付历史计算剩余位置预算。** 原 capture 到现在、尚未显现的相机工作，加上现有整形器自然衰减的余量，先消耗剩余误差。只减少同向位置追赶，不提前反向；目标持续移动所需的输出不算成多余刹车工作。最小追赶参考、曲线、二维力限和手动仲裁继续有效。
3. **物理相机模型跨 ADS/BodyLock 连续。** 物理开镜状态决定先验，控制阶段完成不切换相机。用同一 capture 区间的实际命令联合识别响应与已有生效时差，先对齐再去掉相机运动；目标运动历史随响应单位换算，保持物理速度连续。

新的辨识器使用 16 个观测区间、0–30 ms 候选时差，有足够激励且残差合格才更新；局部目标漂移作为二维仿射干扰分离。证据不足保留先验/既有标定，不获得额外控制权限。它估计现存时差，不排队、不推迟输出；没有新增公开配置。原 12 ms lookahead 只使用尚未被交付预测覆盖的部分，避免重复刹车；既有 25 ms 近点预算不改值。

新增只读日志：`closing_rate_x/y`、`stopping_reserve_x/y`、`camera_response_scale`、`camera_effect_delay_ms`、`camera_alignment_valid`。下轮实机可以区分源点抖动、物理模型偏差和输出余量，不再只从最终杆量猜测。

## 回归和闭环结果

五项原生回归覆盖上述不变量；实际日志 93 个 capture 在旧版失败、新版通过，之前的 92 个 solver 组合反例继续通过。完整 DEV CTest 51/51 通过。独立种子在控制实现冻结后运行，未针对其结果调整算法。

开发种子 2026101829/49979693，独立种子 86028157/104395337。新场景每版本 256 例、2,816,000 tick，旧场景另 128 例、1,408,000 tick；均含 2 秒和 20 秒闭环。以下为四种子的逐案例等权均值：

| 场景 | 原版平均误差 px | 修复后 px | 后段 4 px 内时间比例 | 平均误差改善案例 |
| --- | ---: | ---: | ---: | ---: |
| 静止、慢开镜 | 7.404 | 4.264 | 69.1% → 94.7% | 28/64 |
| 移动，含弱证据 | 15.337 | 11.261 | 39.3% → 60.5% | 33/64 |
| 开火、遮挡、框形变 | 20.718 | 10.977 | 18.5% → 25.7% | 45/64 |
| 逐轴人工介入 | 153.175 | 152.381 | 24.0% → 17.2% | 18/64 |

单看独立种子，静止/移动/开火组平均误差分别为 7.775→4.252、13.824→10.320、16.819→10.436 px；不是仅开发种子改善。静止组后段穿越中心次数由四种子平均 48.28 降到 2.53，后段峰值由 16.61 降到 5.46 px。原版 18/64 个静止案例首周期没有连续 50 ms 留在 4 px 内，新版为 2/64。

也存在代价和退化：静止组首次进入 20 px 从 106.33→116.28 ms，移动组 113.27→124.73 ms。静止组首次进 2 px 的有效均值 138.83→170.13 ms，且新版有 8/64 未达到、原版没有；移动首次进 2 px 166.94→362.14 ms。不能将“更少穿过点”描述为所有到达速度更快。手动组包含持续反向/强推，后段贴点比例下降；所有场景的手动权断言仍通过，没有夺回人工输出来提高分数。弱证据和大机动不保证在既有权限内完全跟住。

完整逐案例前后值在 `runs/settling-chain-20261018/results.json`；[夹具与复跑说明](../../tests/settling_chain_20261018/README.md)列明相机、开火、捕获、FIFO 和评分窗口假设。该模型不是实测武器；日志没有完整逐 tick 内部状态。仿真成功不等于实机游戏验收。
