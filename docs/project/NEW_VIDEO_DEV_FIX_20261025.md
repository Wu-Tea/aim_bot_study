# 新录像缺陷的 dev 修复：2026-10-25

此前[录像研究](NEW_VIDEO_ALGORITHM_STUDY_20261025.md)只完成定位。用户本轮明确要求修复，因此直接修改生产 Vision selector，并更新 dev 正常启动使用的 `native/build/Release/cod_native_runtime.exe`。未更改 controller 参数、个人 Profile、模型，未启动设备输出，未同步 clean 或推送。

## 根因和修改

### 1. 身体参考会被逐帧错误框累计污染

原实现固定了宽高比，却仍用上一次获准框的 cue→框顶间距验证下一帧。框顶每次向上错一点，就能累计把瞄点推向 cue；正常人体框回来时又被污染后的参考拒绝。

现在把初次可信身体框、cue、比例保存成同一份标定。后续框必须与这份标定相容，允许身体缩放与有限边缘噪声，不再逐帧重学标定间距。当前可信身体位置仍能刷新，cue 续跟只平移已有身体参考。正常框恢复时可以立即使用。

独立探针保持真实人物和 cue 不动，只让检测框顶逐帧上扩：原先瞄点从 y=266 漂到 236.4，恢复原框后仍不回去；修复后漂移受既有噪声容差约束，最低 y=254.8，原框返回首帧恢复 y=266。并非宣称没有任何检测噪声。

### 2. 同一 cue 能借给多个人，友军标识被 ROI 裁边

原关联只检查“一个人最接近哪个 cue”，没有检查“这个 cue 最接近哪个人”。现在关联要求双向归属；重叠重复框用置信度及稳定顺序消解。人物 ROI 的颜色质心不能绕过独立 cue 归属。

青色友军圆点贴着 ROI 顶边时，原面积占比可从 1.56% 跳到 2.26%，跨越 2% 阈值。现在在原扫描中收集边界信息，仅对紧凑边缘颜色做局部形状恢复；完全位于边缘外时只补一行种子检查。局部组件仍需通过形状验证，没有直接降低全局友军颜色阈值。

### 3. 未配上 cue 的残框、背景框可以覆盖已有身体

原几何保护只作用于配上同一 cue 的框，未配上的头部残框、大背景框反而可以绕过它。现在同一身份的身体证据统一验证完整几何，不以“这帧没配上 cue”为例外。独立完整身体恢复、确实移出旧 cue 的人体，以及明确手动换目标仍有各自通路。

同时收紧大近身框与侧边小物体的身份匹配。此前仅宽松包含关系就能让小物体继承大框身份；现在明显尺度不对称且横向偏离时不再视为同一个人。

旧生命周期在 person 和 cue 都消失后仍可无限保留曾有敌人证据的身份，新物体便能使用跟踪置信度接管。cue-owned 模式现在只用最近真实人物观测保留原有 50 ms 短缺口匹配，再走原有释放流程；持续可靠 cue 续跟不受该人物缺口期限限制。

### 4. 画面边缘膨胀框能标定数百像素的错误偏移

v08 的大框曾以侧边 cue 标定约 296.5 px 横向偏移。现在关联与标定共用身体横向支撑范围，由宽、高共同约束：允许侧身头部靠近肩膀，拒绝巨大横向框借用远侧 cue。独立高置信度 person 仍可索敌，维持 person OR cue，不恢复 AND。

验证过程中也修掉两个中间版本回退：未配上 cue 的相似框不能无条件清除参考；横向范围不能只按较窄身体宽度限制而丢失正常侧身 cue。两者都有原生回归用例。

## 实际限制

换弹时枪身仍可能被模型以较高置信度认成人。旧身份借给错误物体的问题已经修复，但这不能消除模型独立、高置信度的新误检。没有用拒绝全部近身大框或强制 cue AND person 掩盖这个限制，因为那会伤到近身索敌。

没有对所有帧做人工真值标注，目标存在帧数降低不能当作准确率提高。重点减少帧已人工抽查：包括青色友军、倒地尸体、自己的枪、建筑/雕像；也检查并修复了真实边缘人物短缺口和侧身遮挡续跟的回退。

本次没有匹配的真实手柄日志。开放回放包含视频原有镜头运动，近似闭环使用合成输入、延迟和简化反馈，不会重新渲染世界。数值不变量通过只验证这些假设下的算法行为，不代表实机验收。当前身体框也不提供可靠头部可见性，未新增胸部到头部切换。
