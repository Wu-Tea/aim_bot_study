# 被动减速未触发：闲时权限判断修复

> **2026-10-23 用户决定撤回整个被动减速功能。** 以下权限根因与验证属于历史分析，不能理解为当前 dev 仍启用此功能。用户希望未来方案覆盖高速转镜头，因边界和测试工作较大先暂缓。代码与专用实验已退出当前生产/测试目录，研究源文件存于 `runs/passive-friction-rollback-20261023/archived-experiment/`；原日志、回放结果保留。

2026-10-23，仅 dev。50% 强度保持，已完成正常 Release 构建，未提交/push，clean 未改。

## 根因与证据

用户反馈 50% 仍没有感觉，提供 `Call of Duty  Black Ops 7 2026.10.23 - 18.23.32.02.mp4`。录像 12.542 秒、1920×1080、120 fps；对应 dev 会话为 `runs/native_perf/sessions/20261023T102306Z_41560_1/`，18:23:06–18:23:50，单份遥测约 41 MB。录像文件名与日志时间仅作近似对齐，没有精确逐帧时钟校准。

去重后 2,801 条 controller 样本，仅 3 条 `passive_target_friction`，发生在 18:23:41.791–41.800，均只减弱 Y，X 完全没有减速。这三条位于释放 ADS 后，短暂沿用了仍新鲜的 ADS 快照。controller 标记均已交付；其中后两条还可与邻近独立 delivered 样本精确匹配，第一条没有相应精确记录。

真正的失败边界是权限职责混用：

1. `VisionService` 对 Idle / DetectionOnly 发布结果主动清除 AI 瞄准、开火权限。这是正确行为。
2. 被动减速只在未激活 AI 的 Off 状态运行，却同时要求 `aim_authority=true`。
3. 因而正常闲时检测即使提供可靠敌人和身体几何，也被减速函数拒绝。

最初怀疑置信度 0.5 门槛过严，但这不能解释所有未触发样本，本轮没有调整置信度。此前模拟快照错误地在闲时保留 `aim_authority=true`，绕过了真实服务边界；旧拟真通过不证明实机闲时功能可用，这是此前验证的遗漏。

## 最小修复

`passive_aim_friction.h` 只移除对 AI 瞄准权限位的依赖。继续使用已有新鲜敌人证据，保留身份、置信度、身体几何、当前 cue_hold、观测过期及手动/ADS/开火状态限制。VisionService 的撤权规则不改，被动减速不会获得 AI 或开火权限。

50% 峰值、位置渐弱、45%–75% 推杆淡出、≥75% 原始透传保持；没有新检测、同步等待、锁、分配或定时器。旧模拟改为真实闲时权限，避免以后再次掩盖问题。

## 验证

- 新增真实 `VisionService → delivery gate → production adapter → NativeGamepadController` 回归 `passive_friction_without_ai_lease`：修复前失败，修复后通过。覆盖 Idle、DetectionOnly、person、cue_hold、ADS 排除及过期恢复；AI/fire 权限始终关闭，合格输入 0.4→0.2。
- 完整 CTest **51/51**，Base **483/483**；正常 dev runtime 已重建。
- 录像窗口 957 条控制样本中，195 条 ADS/开火排除、537 条无 selector 目标、45 条无法重建身体几何，剩余 **180 条**可由同帧 selection、committed observation、acquisition trace 重建为 direct-person Off 输入。按真实闲时撤权规则回放，旧函数触发 0 条，修复后 **47 条**（X 33、Y 26，有重叠）；15 条强推杆样本全部原样输出。
- 例如日志 18:23:41.028 附近，X 输入 −0.254913，修复后的离线输出 −0.130047，约减速 49%；Y 保持原输入。这是离线证据重建，不是修复后游戏实测。原日志 3 条沿用 ADS 权限的样本不能与重建的闲时 0 条混作同一统计。
- 重跑 160 个日志组合、27 个定点刹停、两个独立种子的 128 个 2/20 秒场景，每版 1,408,128 tick。持续 ADS 和 95% 转身对照一致，获取时间/拥有目标覆盖不变；激活状态不直接应用被动减速。

50% 仍有明确强度代价：固定手势的强制 Off 压力组合平均误差最多增加 21.298 px；低响应定点例由越过 1.688 px 变成提前 14.179 px 停下。先减速后激活时，输出历史引起的最大单轴差异为 0.010362，不能宣称跨状态完全零影响。按用户要求保留 50% 供实机试用，没有自动降回 8%。

三轮交替测量完整 `build_output`：修复前均值 **1.259–1.292 μs**，修复后 **1.259–1.273 μs**；场景 P95 中位数约 1.9–2.0 / 2.0 μs。未测出超出噪声的增加，没有更改检测频率；这不是实机 FPS 测量。
