# 手柄控制链路：本轮实际改动与验证

本轮完成了视觉置信度和输出学习记录两处修复，独立检查版本已编译。**过冲与摆动尚未解决，当前版本不满足发布条件。** 日常启动的程序保持原版本。本文对应全链路审计之后的实现，不能用本轮结果替代实战验收。

程序需要根据画面变化判断目标怎样移动，同时扣除自己刚才推动镜头造成的变化。如果把目标选择的加分当成检测准确度，或者把尚未发出的摇杆指令当成已经发生的镜头运动，后续算法就会依据错误的信息纠偏。本轮先修正这两处信息来源。

## 保留的修改

**色标加分与检测置信度分开。** 原来检测置信度 0.65 加上色标的 10000 分，会被压到 1.0，等于把这次检测当成完全可信。现在 controller 收到的置信度仍是 0.65；色标、敌人身份和选择结果通过各自字段传递。适配器同时按检测本身的置信度判断候选是否有效，不允许加分挽救无效置信度。修改位于 [vision_controller_adapter.cpp](D:/work/AI/yolo-study-001/native/runtime_app/vision_controller_adapter.cpp)。这纠正了置信度的含义；带色标目标的实际控制强度可能因此变化，仍需实战确认。

**学习记录由发送结果确认。** 原来 controller 在计算指令时就记下压枪之前的摇杆值；记录发生在最终组合、DS4 量化和发送成功之前。现在运行时在 ViGEm 成功接受报告后，才把该报告的右摇杆字节还原并交给学习记录。记录包含最终组合与量化的结果，时间使用提交报告的时刻。发送失败会中断这段证据；同一帧内重连成功也会中断，因为初始化设备时另外发送过中立报告。恢复后由新的成功报告重新建立运动证据。

这部分涉及 [native_gamepad_controller.cpp](D:/work/AI/yolo-study-001/native/controller_native/native_gamepad_controller.cpp)、[virtual_gamepad.cpp](D:/work/AI/yolo-study-001/native/controller_native/virtual_gamepad.cpp) 和 [runtime_loop.cpp](D:/work/AI/yolo-study-001/native/runtime_app/runtime_loop.cpp)。ViGEm 接受报告仍不等于游戏已经消费报告，因此游戏响应延迟仍是待估计量。本轮修复的是响应学习和运动观测器共用的指令历史；其他预测器中的历史状态没有全部改成发送回执。

上述修改没有新增摇杆死区、平滑滤波或制动增益。物理输入的零软件死区，以及此前工作区的 15–30% 人手意图渐变曲线均保留。

## 为什么没有保留运动估计的改法

运动估计内部存着经过手柄响应比例归一化的速度。响应比例一变，同一份历史就可能被解释成不同的实际速度。本轮试过改为保存像素/秒，局部测试证明它能修正这个单位错误。

但闭环测试出现了索敌损失：一个纯 AI 场景获取目标数从 5 降为 4，16 个参数包均有受保护指标未通过；已知静止目标摆动也没有改善。按“不影响索敌”的约束，这部分已撤回。失败版本、测试与结果保存在 `runs/chain_refactor_20260926/rejected-units/`、`units-red/` 和 `units-matrix/`，没有修改阈值使其通过。

这说明修正单位本身还不够。剩余问题需要把手柄响应误差、输出延迟与运动补偿放在同一个模型里处理，否则自身镜头运动仍可能被解释成需要追踪的目标运动。这个解释由合成反事实支持，尚不能等同于真实 Warzone 辅瞄的已确认根因。

新增问题先用旧实现复现失败：置信度回归与“未发布提案不能学习”的回归都失败，然后修改实现使其通过。发送失败后的连续性检查位于输出信任边界，避免把未知的硬件输出当成已知镜头运动；它不是用于压住正常摇杆信号的滤波门。

这里的比较基线是**本轮开始前、已经包含 15–30% 曲线的工作区版本**。它不是最初的 25% 硬阈值版本，也不是日常正在使用的旧程序。此前 15–30% 候选相对最初基线仍有 12/16 个参数包未通过，本轮“没有新增退化”不能把那些失败抵消。

模拟覆盖也有明确限制：Sustained 使用浮点输出的模拟接口；随机扫描的游戏模型使用 DS4 量化，但学习回执仍来自浮点接口。实际 runtime 使用 DS4 字节还原后的回执，这一差异由新增的回执测试检查。大矩阵没有完整经过真实视觉检测、色标识别和硬件发送，因此不能证明置信度调整在真实游戏中无退化，也不能证明强辅瞄场景已经改善。结果状态保持 **EXPLORATORY / MISSING COVERAGE**。
