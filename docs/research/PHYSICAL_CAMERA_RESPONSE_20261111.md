# Hipfire / ADS 单一响应模型

2026-11-11 用户最终确认：减速区与非减速区使用完全相同的响应数据；保留自动学习，但不再区分区域。Hipfire 和 ADS 按实际腰射／开镜状态区分，与首次瞄准／持续跟随阶段无关。

## 最终行为

- 每种相机状态只有一份初始响应、一份学习结果和一份置信度。进入游戏辅助瞄准范围，不选择另一份响应，不插值或补偿区域响应，也不根据区域排除标定样本。
- 自动学习继续更新当前相机状态的共享响应。因而开启学习时响应可以随证据变化；它不是固定为 500，也不是固定不学习。关闭自动学习时使用用户初值及既有继承规则。
- 实际开镜后，即使控制进入持续跟随，仍使用 ADS 数据。腰射与开镜切换时，测量区间重新起算，已学到的数据分别保留；相机增益／延迟拟合也分别归属这两个相机状态。
- 两种状态使用同一套稳健响应估计方法，控制阶段转换不切换学习算法。原有数据可信度、开火干扰、手动歧义、真实输出回执和目标连续性约束保持有效。
- 旧配置中的 `body_free_initial_scale` 和 `ads_free_initial_scale` 分别作为 Hipfire 和 ADS 初值保留读写兼容。两个 `*_slow_initial_scale` 仅兼容读取，不进入有效配置、热更新比较或控制；不批量改写用户配置。
- 设置页和运行反馈只显示“腰射（Hipfire）”“开镜（ADS）”。保留自动学习开关及双曲线预览。学习通道升级为协议 2、两个模型，旧协议会明确拒绝，避免错读内存布局。
