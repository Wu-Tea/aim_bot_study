# 曲线库、通用转译与初始响应

2026-11-11 更新：本文中的四区域响应部分已被 [Hipfire / ADS 单一响应模型](PHYSICAL_CAMERA_RESPONSE_20261111.md) 取代。最终仅保留两个物理相机状态的共享响应，保留自动学习，不区分减速区域。

本轮按用户反馈撤下 COD 专用补偿界面和页面实现注释。2026-11-11 最终确认：曲线库负责数据准备；配置页独立选择用户输入转译曲线和 AI 输出解算曲线。用户输入始终采用所选曲线，不需要转译时选择线性 1:1，不再提供额外开关。配置页不选择游戏基准曲线，不在切换选项时制作融合。响应初值单独放在转译设置首屏。

## 数据从哪里来

- `resources/curves/*.json` 是内置曲线库，包含线性、COD Linear 与 COD Dynamic 历史数据。文件包含名称、控制点、插值方式和来源；用户曲线与内置曲线使用同一格式。
- 用户曲线保存在 `profiles/curves/`。支持新建、临时导入、导入后保存、编辑、重命名、另存、导出及可恢复归档。内置数据只读，编辑后存为用户副本。
- 旧配置的两个 COD 算法名称继续可读。CMake 从同一 JSON 生成兼容用数组，源码中不再维护另一份测量点；新增配置走通用数据输入。原生构建和控制不调用 Python。

## 怎么计算、怎么应用

基准 A 表示已有游戏响应，目标 B 表示期望响应。生成 C = A⁻¹ ∘ B。折点取 B 的折点与 B⁻¹(A 的响应折点)的并集，再去除数值共线点。不会用一个凭空设定的幂指数代替输入数据。

仅在曲线库的“制作融合曲线”中选择 A/B，展示 A、B、C；输入验证值后计算 A(C(x)) 并比较 B(x)。C 先存入曲线库或导出，其来源保留 A/B 名称与控制点快照。

配置页从库中独立选择输入 C 和 AI 响应 B。配置保存 C 本身及 B 的控制点快照，不保存对库文件的活动引用，不隐式绑定 A/B/C。修改或归档库中数据不改变已保存配置；同一曲线的配置快照不重复添加成“当前曲线”选项。

配置页保留双曲线实时预览：用户输入用黄色虚线，AI 响应用蓝色实线。选择曲线即刻更新草稿预览。滑块读取同一输入位置的用户输出和 AI 曲线响应；预览不代表已经保存或运行生效，状态由应用统一保存流程显示。浏览器覆盖 50% 输入下 46.14%/21.03% 读数、滑块更新及输入改选线性 1:1 后 AI 曲线保持不变。旧配置若关闭手动转译，页面按实际行为显示线性 1:1；读取不改写配置，显式选择曲线并保存后才启用该映射。

- 游戏 Linear A、期望 Dynamic B：输入选择预先制作的 C=A⁻¹∘B，AI 选择 B。
- 游戏已是 Dynamic B、手动保持直通：输入选择线性 1:1，AI 选择 B。
- 用户也可使用自己导入的任意合法单调曲线，不要求说明游戏曲线。

原生 `output_lut` 将 C 作为最终输出坐标映射。AI 始终按独立选择的 B 解算，输出反馈通过 C⁻¹ 回到该解算坐标；禁止把 C 当成 AI 响应曲线或重复应用 C。启用手动转译时手动命令按 C 输出；关闭时先将原始手动输入转换回内部坐标，最终保持原始直通。手动意图和各轴权限始终读取物理输入。

曲线最多 128 点，使用固定容量原生数组；超过容量或转换成 float 后出现重复坐标时明确拒绝，不静默丢点。旧版 32 点限制不足以保存已有 38 折点的组合。数据只在配置加载时解析，控制 tick 不读文件、不增加分配或等待。

旧幂函数和专用算法只保留配置兼容，不作为新页面入口。读取旧配置不自动改写；可表达的旧补偿以输入快照呈现，用户保存新曲线设置时写入新的独立 C/B 模型。

页面明确显示未保存、已保存待启动、已保存待重启、运行中已生效。运行进程记录启动时的曲线快照，保存文件不改写该证据；待重启时并列展示已保存和正在使用的曲线，并提供重启入口。旧运行记录缺少证据时显示待确认。区域初始响应仍支持原有热更新。

## 初始响应与学习

此前 4000 上限同时存在于 Python 表单、原生配置校验、学习器、相机响应对齐及运动观察器。现移除固定游戏响应上限，仅保留有限数、原有最小有效值和原生浮点可表示边界；没有换成另一个任意业务上限。

四个区域初始响应放在首屏，空值显示“自动”并保存为原有继承值 0。未改动默认初值、手动权限、学习样本可信度、视觉频率或输出力度限制。初值过低可能造成误差到输出的换算过强；本轮只修复配置与估计的范围限制，不宣称解决所有实机抖动。

## 验证

- 原生基础回归 537/537；随后新增混合输入闭环后，曲线相关 11/11；相关功能 CTest 4/4。
- 新增 8000、25000 配置与学习验证；四区域高初值的清空、重置、热更新及手动释放；四个确定性场景的高响应相机对齐和运动消除。
- 新增预制 C 和独立 B 的完整控制链闭环，96 组、441600 tick，含手动输入、各轴修正、目标间隙和释放。另用四个独立随机种子、300/12000 tick 验证两种 C、手动开关、原始意图及 AI 解算反馈。仿真不是实机验收。
- 桌面 94 项通过，含 48 对确定性随机单调曲线的 48048 个组合验证点、COD 源数据的 10001 点复合检查、来源往返与归档、配置快照独立、独立 C/B 原生往返及运行绑定不可被保存篡改。
- 浏览器验证库内计算及三曲线、保存入库后独立选择 C/B、1:1 输入搭配 Dynamic AI、快照去重、8000 初值、全局草稿与曲线状态同步、保存/重开/运行/待重启/重启生效闭环、1360/1024/800 宽度。测试使用临时数据和非执行型运行替身，没有启动控制输出。
- 新模型的本机 Off/无目标控制链微基准约 0.74–0.79 μs/tick，无逐帧数据解析、分配、平滑或等待；这是离线成本，不代表游戏帧率或延迟。
