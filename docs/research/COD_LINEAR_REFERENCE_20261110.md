# COD Linear 旧版参考补偿

后续用户反馈已将专用 UI 改为通用曲线库与 A/B 换算。本文保留数据研究过程；当前实现与使用方式见 [曲线库、通用转译与初始响应](CURVE_LIBRARY_AND_RESPONSE_20261110.md)。下方旧菜单及专用开关描述不再代表当前页面。

2026-11-10：用户要求在 MW4 游戏内使用 Linear 时，反算程序输出，使最终响应接近助手当前动态曲线。用户同意先加入旧版参考补偿，再实机调整；提供斜率 1、死区 0。最大输入端按 100% 建模，未确认游戏最大死区设置。

## 数据与边界

- 原始数据：[Controller Curve](https://docs.google.com/spreadsheets/d/1186qbRXRd0tH_tennRF2tkxz-wTv3hExb4drmNDdPkQ/edit)，Sheet1 B2:U4 为 Dynamic，B7:U9 为 Linear。
- 当前 `kCodDynamicLegacyStick/Response` 与此表的 Dynamic 位置及归一化转速一致（表中 Time 为每圈秒数；归一化响应为满杆每圈时间除以采样每圈时间）。
- Linear 的 50.185% 输入对应 `0.366 / 1.466 = 24.9659%` 满速响应。这证明该历史样本不是纯直线，不证明 MW4 当前版本具有相同函数。
- [2024 年讨论中的原表链接](https://www.reddit.com/r/CODWarzone/comments/1h0abed/)可追溯这份旧数据。未找到可核实的 MW4 完整实测表；旧表没有提供当前 MW4 的斜率设置或游戏版本。
- 目标是归一化静态转速曲线，不是绝对角速度、游戏输入延迟、时间加速、ADS 过渡或敌人附近的瞄准减速。0 至约 10% 输入区只有端点插值，不能称为密集实测。

## 计算及归属

令 `D(x)` 为当前动态目标响应，`L(u)` 为历史 Linear 响应，补偿输出 `C(x) = inverse_L(D(x))`，因此 `L(C(x)) = D(x)`。

例：物理输入 50%，动态目标约 21.0323%；补偿杆量约 46.1433%，经过参考 Linear 模型后得到 21.0323%。直接输出 21.0323% 杆量，在同一模型中只能得到约 4.4197% 响应。

实现复用 `game_stick_transfer.h` 的输出边界，新增可选 `response_model = "cod_linear_legacy_lut"`。手动、AI、独立压枪合成后统一反算；输出反馈用同一模型正向解码，避免把补偿后的杆量误当相机响应。原始输入仍负责手动权限、退出和换目标；不新增逐帧分配、缓冲、平滑或额外控制门槛。

现有幂函数模式与默认关闭状态保留。选择参考模式时幂指数不参与计算；死区补偿仍是独立标定值，零死区预设使用径向模型、死区 0。

## 使用

响应曲线页选择目标曲线，在图表上方“游戏响应补偿”选择“COD Linear · 旧版参考”。该操作在草稿中开启跟随曲线和输出补偿、选择旧版模型、设死区 0 和径向补偿；保存并重启后生效。不会直接覆盖用户 Profile 或自动启动控制输出。

页面同时显示目标响应（蓝色实线）、游戏参考响应（灰色虚线）、程序输出（黄色点划线）。右侧“验证补偿结果”可调整 0～100% 的验证输入，显示目标响应、程序输出、预计游戏响应及偏差；修改目标控制点、开关补偿会同步更新图线与读数。数据从原生参考数组读取，前端没有另一套手填曲线。关闭补偿时仍显式使用零死区 COD 参考估算响应，展示剩余偏差；启用幂函数时改用配置中的幂指数和死区。验证是单轴静态模型，不含量化、时间加速或实机反馈。

“参数调校 → 输入与手动 → 游戏响应补偿”可查看与修改设置。游戏内选 Linear，斜率 1，最小死区 0；最大端按 100% 试用。参考不是 MW4 实机标定。

## 验证方式

- 原始数据独立计算：10001 个输入点验证复合曲线；精确分段复合共有 38 个折点，因此运行时直接组合两次查表，不强塞进最多 32 点的用户曲线。
- 原生测试覆盖单轴/斜向、端点、死区、DS4 量化、关闭恢复、目标跟随与过期、输出反馈解码。
- 增补 96 组、441600 tick 的延迟闭环模拟，检查手动权限、退出、目标缺口及身体瞄点；沿用明确的合成目标、相机和压枪模型，不是实战复原。
- 本轮计算产物位于 `output/cod-linear-reference/`；测试记录为 `output/cod-linear-*.log`。测试实际结果以日志为准，不作为实机验收。

## 本轮验证结果

- 原生 Release 构建、前端 Vite 构建通过；基础测试 535/535，相关功能 CTest 4/4，桌面配置测试 89/89。
- 补偿闭环模拟 96 组、441600 tick：无非法输出、过期视觉权限或手动释放恢复失败；源瞄点最大漂移约 0.0000042 像素。
- 独立双精度计算 10001 点，参考模型复合后的最大归一化误差为 `1.11e-16`。这只证明该分段模型的反算一致性，不代表真实游戏误差；原生 float、DS4 报告量化另有回归覆盖。
- 本机离线微基准：动态映射约 24 ns/次，加入参考反算后约 43 ns/次，增加约 19 ns；不代表实机 FPS 或整体输入延迟。
- Edge 浏览器通过菜单启用、保存重载、关闭补偿保留目标曲线的检查；1360、1024、800 三种宽度无横向溢出，无页面异常。截图在 `output/playwright/cod-linear-reference/`。浏览器使用临时 Profile，未启动控制输出。
- 页面闭环补充：前端构建与 89 项桌面测试通过；JS 模型验证动态/自定义/线性目标、COD/幂函数以及零/非零死区，共 120012 个组合采样通过。浏览器验证三条图线、关闭后的偏差、自定义点修改同步、键盘输入验证端点及保存重载；四种窗口尺寸无横向溢出，截图在 `output/playwright/curve-visible/`。
