# 桌面交互闭环检查（2026-11-11）

本轮按用户要求检查五个工作区的进入、编辑、保存、返回、取消与失败恢复。改动仅涉及 React 界面及浏览器回归，不改变原生控制算法、检测频率或用户配置。

## 操作归属

| 场景 | 修改落在哪里 | 完成操作 | 取消、返回与失败 |
| --- | --- | --- | --- |
| 参数、设备、转译设置 | 当前配置草稿 | 顶部保存配置；运行中保存并应用 | 返回保留草稿；保存失败保留值；纠正非法字段后清除对应旧错误 |
| 曲线库编辑 | 曲线库草稿 | 保存曲线／保存为副本；Ctrl+S 保存当前曲线 | 返回后继续编辑；放弃修改需确认；写入失败可重试 |
| 精确点位编辑 | 未应用的点位文本 | 应用点位，再保存曲线 | 可取消点位编辑；未应用时不写入配置或曲线文件 |
| 融合制作 | 曲线选择、结果、名称和验证位置 | 存入曲线库；Ctrl+S 保存计算结果 | 返回保留；放弃制作需确认；未计算时说明下一步 |
| 完整配置 | 文本编辑，然后是配置草稿 | 校验并载入草稿，再保存配置 | 校验失败保留原文；关闭、Esc 和取消均保护未应用修改 |
| 配置管理 | 独立配置文件或名称 | 创建配置、创建副本、保存名称、导入配置 | 确认框保留失败输入；取消不提交；成功说明对应对象 |
| 导出 | 用户选择的文件 | 成功显示导出路径 | 取消明确显示取消，不显示成功 |
| 删除／归档 | 已保存对象移入备份／归档 | 明确确认后移除列表对象并反馈 | 取消保留对象；失败保留当前编辑视图和重试入口 |
| 关闭应用 | 所有配置及曲线工作区的未保存状态 | 无草稿直接关闭；有草稿列出涉及对象后确认 | 包含新建、临时导入、待应用点位和未完成的融合草稿 |

顶部“保存配置”作用于配置；曲线库自己的保存按钮作用于曲线库。底部 Ctrl+S 提示随工作区变化。切换工作区、配置、返回列表都不是保存操作。关闭应用后不能恢复未保存的内存草稿，因此关闭确认纳入所有曲线工作区，而非只检查配置差异。

## 保存与运行状态

- 写入失败：保持未保存，保留输入和重试机会。
- 仅保存配置：显示待应用。
- 已提交但等待运行程序确认：显示等待应用。
- 热加载失败：配置仍已保存，运行状态显示应用失败，提供重试应用。
- 收到成功确认：显示已应用。
- 曲线与启动时绑定不同：显示待重启。
- 重新打开界面时，只凭曲线绑定相同不能证明所有参数已经应用；显示运行中，不虚构一次应用确认。

## 发现并修复的问题

1. 曲线库中的 Ctrl+S 原先调用配置保存，写错对象。
2. 关闭窗口原先只检查配置草稿，曲线和融合草稿可能直接丢失。
3. 临时导入／新建但尚未修改的曲线不被认为待保存，返回时会被清掉。
4. 取消编辑直接清空修改，缺少明确的放弃选择；完整配置的取消和 Esc 也有同类问题。
5. 仅保存或热加载失败后可能仍显示已应用。
6. 成功重试仍可能留下旧错误；纠正字段后对应错误未消失；弹窗会显示无关的全局旧错误。
7. 归档、重新载入、恢复初值及文件选择取消缺少明确的结果反馈。

- 桌面服务与配置测试 96 项通过，包含文件冲突、保存持久化、模型校验、运行失败、曲线导入与归档等已有契约。
- 新增交互回归对 RPC 边界注入读取、保存、重命名、归档、热加载失败及文件选择取消，检查保留输入、重试、落盘反馈和异步确认。
- 前端构建与差异空白检查通过；复核 1348×928 的运行失败状态和曲线编辑画面。

这些结果验证界面与服务契约；没有在本轮启动真实游戏控制，也不把运行替身测试等同于实机热加载或系统文件选择器验收。

## 提交前清理

用户输入始终采用所选转译曲线，线性 1:1 即直通，取消额外转译开关；AI 解算曲线独立。旧关闭配置显示实际直通状态，读取不会自动改写。统一选择框保留原生键盘与焦点行为，深色菜单和长文本省略由共享样式负责。

曲线库已接管编辑流程，删除不可达的旧预设弹窗、两项旧预设接口及对应样式；删除配置页无人消费的撤销栈、重复点位状态与编辑器空回调。曲线库自己的点位草稿、返回保留和关闭保护仍是唯一有效路径。移除未使用的 `translation_name` 专用校验；实际转译名称继续由输出曲线配置和曲线库管理。

清理后重新通过前端构建、桌面 96 项测试、原生 539 项回归、五组浏览器流程及隔离桌面的真实 WebView2 检查。五个主页面在 1348×928 下均无内容区溢出。验证日志为 `output/cleanup-*.log`。
